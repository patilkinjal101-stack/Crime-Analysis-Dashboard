SAFESTREET PRO — CRIME PATTERN ANALYSIS WEBSITE

TECHNOLOGY
- Python 3.x
- Flask
- HTML5
- CSS3
- JavaScript
- Chart.js

RUN IN VS CODE
1. Extract the CrimePatternAnalysis folder.
2. Open the folder in VS Code.
3. Open the VS Code terminal.
4. Create/activate a virtual environment (recommended):
   python -m venv venv
   Windows: venv\Scripts\activate
5. Install dependencies:
   pip install -r requirements.txt
6. Start the Python Flask server:
   python app.py
7. Open http://127.0.0.1:5000 in your browser.

FEATURES
- Python Flask backend for crime-data API.
- Dashboard filters for area and year.
- Crime type, area and monthly charts.
- Demo crime-report API endpoint.
- Responsive HTML/CSS interface.

IMPORTANT
All crime data is fictional sample data for educational purposes.
The report endpoint does not permanently store reports and is not an official police reporting service.
Chart.js loads from a CDN, so internet access is required for charts.
