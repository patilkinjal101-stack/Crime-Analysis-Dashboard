Turning sample data into useful insight.

Crime Pattern Analysis & Community Safety Dashboard is a student-friendly demonstration website. It presents fictional data in a simple interface to show how crime categories, areas and time periods can be explored.

Project objectives

  • Present crime statistics in a clear dashboard.
  • Compare sample cases by type and area.
  • Explore monthly patterns using charts.
  • Demonstrate a basic community concern form.

Technology used

Python (Flask) · HTML · CSS · JavaScript · Chart.js

All displayed counts and locations are fictional sample values. They do not represent actual crime records.
